## 一、设计哲学与核心原则

1. **本地优先（Local-First）与绝对隐私**：
   - 所有小说稿件、人物卡、大纲及字数统计均保存在本地计算机上（`127.0.0.1` 本地环回）；
   - 绝不静默上传或外泄任何用户原创未发表文稿。
2. **纯 Python 标准库后端（零外部重量级框架）**：
   - 彻底摆脱复杂的第三方 Web 依赖，任何标准 Python 3.10+ 环境即开即用；
   - 采用持久化 SQLite 结合 WAL 模式，确保百万字小说高并发读写与断电零损坏。
3. **创作原文神圣不可侵犯**：
   - 章节入库全程受互斥原子快照锁（`_CHAPTER_WRITE_LOCK`）保护；
   - 具备幂等防重记账机制，绝不发生覆盖、丢失或乱码损坏。

## 二、快速启动与环境准备

### 1. 桌面端启动
- **便携安装版**：双击运行 `Start.bat` 或桌面快捷方式，系统将自动分配空闲端口（默认 8000，冲突自动递增）并拉起浏览器。
- **开发者控制台**：
  ```bash
  python -m gui.server --no-browser --port 8000
  ```
- 访问地址：浏览器打开 `http://127.0.0.1:8000/` 即可进入现代化墨韵工坊界面。

## 三、从零到一创作全流程（Golden Path）

```mermaid
flowchart LR
    A["语料导入 / 示例试手"] --> B["五遍深度拆书"]
    B --> C["沉淀声音卡 Voice Card"]
    C --> D["大纲架构 & 人物卡落库"]
    D --> E["协作正文起草"]
    E --> F["双栏审校对比"]
    F --> G["去 AI 味全维诊断"]
    G --> H["DOCX / MD 出版导出"]
```

### 1. 语料导入与样本体验
- 进入 **「拆书分析」** 页面，支持两种导入形式：
  - **就地引用导入**：输入本地 `.txt` 绝对路径（系统就地解析分章分批，不占用冗余磁盘）；
  - **新手一键示例**：点击「示例语料」，内置《校园救赎》《诡秘悬疑》等原创样例，一键试手秒级体验。

### 2. 五遍扫描与深度拆书
- 选择目标题材（如 `campus-redemption` 或 `xuanhuan`），点击 **「开始拆书分析」**：
  - **Pass 1 笔法扫描**：解构叙述视角（POV）、体感描写密度与金句特征；
  - **Pass 2 情绪张力**：刻画情绪起伏波形、虐点伏笔与甜点补偿；
  - **Pass 3 结构观测**：拆解章内分节节奏、钩子悬念与转折推进；
  - **Pass 4 商业打法**：提炼爽点闭环、打脸拍子与期待感铺垫；
  - **Pass 5 聚合报告**：产出万字深度结构报告，沉淀为标准的声音卡（`Voice Card`）与笔法卡。

### 3. 大纲架构搭建与拖拽排序
- 进入 **「写作工作台 - 大纲架构」**：
  - 点击 **「新建大纲」**：设定卷号、章节主题、核心冲突、反转节拍与伏笔回收点；
  - **上下移与拖拽重排**：点击「上移」「下移」按钮，系统通过底层批量原子事务接口立即同步更新章节排序，保障剧情脉络井然有序。

### 4. 人物关系网络与卡片管理
- 进入 **「写作工作台 - 人物关系」**：
  - 创建主角、宿敌、配角卡片；
  - 设定**阵营归属**（如正派、反派、中立观察者）、**核心性格特征**与**终极欲望动机**；
  - 自动渲染人物卡片树，直观查看人物关系网络，避免长篇连载时出现人设崩塌或配角失忆。

### 5. 写作工作台与双栏对比审校
- 结合声音卡一键注入 System Prompt，在智能会话中完成章节草稿；
- 切换至 **「双栏对比审校（Diff Review）」** 视图：
  - **左栏**：当前已落盘版本正文；
  - **右栏**：AI 优化润色版本（段落级比对）；
  - **差异高亮**：精准标注增改修饰，支持「一键采纳优化」或「逐段合并」，告别整章盲目替换。

### 6. 去 AI 味全维诊断与润色优化
针对大语言模型常见的生硬表达，系统内置纯算法的 6 大维度深度筛查：
- 🔍 **假大空玄虚修辞**：过滤「浩瀚如烟海、难以言喻、滔天巨浪」等悬浮套话；
- 🔍 **直陈式情绪喊话**：纠正「他非常生气、极为愤怒」，指引改用生理反应与即时动作（Show, don't tell）；
- 🔍 **极端程度副词**：拦截「极其、极度、无比、万分」等粗暴堆砌；
- 🔍 **空洞口癖连接词**：筛查「不得不说、说实话、可想而知、只见」；
- 🔍 **「让」字被动句密度**：压制过度使用「让…产生…」的翻译腔，重构为主谓主动句；
- 🔍 **机械连续同构排比**：识别连续工整句式，打破「AI 说明书感」，注入真人写作的参差呼吸感。

### 7. 多格式出版级规范化导出
在写作台点击 **「规范导出」**，支持三种工业级格式一键下载：
- 📄 **Word (.docx)**：
  - 纯 Python 标准库构建合法 OpenXML 包；
  - 内置书名扉页、大纲目录、标准三号加粗章标题与首行缩进正文排版，直接满足出版社与编辑部审稿规范。
- 📝 **Markdown (.md)**：
  - 规范的二级章节标题、段落分隔线，适合直接导入 Obsidian、Notion 或静态博客。
  - 包含总字数、创建时间与章节统计元数据。
- 📋 **纯文本 (.txt)**：
  - 适合各大网文作者专区后台批量上传。

## 五、平台投稿合规自检与一键排版

进入 **「系统 / 平台工具」**：
- **主流平台规则预置**：
  - **起点中文网**：2000 - 5000 字/章，强主线期待感；
  - **番茄小说**：1800 - 3000 字/章，快节奏高频钩子；
  - **晋江文学城**：3000 - 6000 字/章，细腻情感流动；
  - **知乎盐言**：8000 - 15000 字短篇，强反转与高密度冲突。
- **一键自检**：检测字数合规性、标题章号重复、敏感词预警，确保过审率。

## 七、系统安全、故障自愈与常见问题（FAQ）

### Q1: 忘记了管理后台密码怎么办？
- 首次启动时，系统会在用户数据目录下的 `admin-初始密码.txt` 文件中生成初始随机密码；
- 该密码在首次登录并修改密码后，会自动安全自毁销毁；
- 若忘记已改密码，删除数据目录下的 `admin.json` 并重启服务，系统将重新生成全新的安全凭证。

### Q2: 为什么提示「登录失败次数过多，请 5 分钟后再试」？
- 系统内置安全防暴力破解机制，同一 IP 连续输入 5 次错误密码将自动触发 429 锁定 5 分钟，锁定期间拒绝所有认证尝试，保障本地资产安全。

### Q3: 端口被占用服务能启动吗？
- 可以。系统内置智能端口寻优算法（A5 决策），若默认 8000 端口被其它应用占用，将自动在 8000-8099 范围内递增寻找可用端口绑定，无需手动修改配置文件。

### Q4: 崩溃或强制退出后提示「单实例锁存在」怎么办？
- 系统内置 **Stale Lock 自动清理与自愈机制**。启动时会自动使用标准库底层句柄探测持有该锁的进程是否存活；若判定为非正常退出的死锁（Stale PID），会自动原子清理并正常拉起，无需手动删除 `.lock` 文件。
