## 二、与 novel-lab 工具链的配合关系

```
拆书阶段:  novel.py 拆书(本地采样量化) → AI 读 pass1-5 prompt 产出分析 → normalize/校验/合规入库
           （可并行）webnovel-reverse-analysis / fingerprint_extract.py 做指纹交叉验证
聚合阶段:  pass5_aggregate.py（≥3本 → 题材包）
写作阶段:  novel.py 注入(资产生成 prompt) → AI 会话内写正文（write.py 生成的接管文档给出保存路径+自检命令）
           → novel.py 检查（12维+一致性，本地打分）→ 达标入库
润色阶段:  story-deslop 去AI味 → 再跑 novel.py 检查 回归
```

**关键分工**：本地 Python 工具 = 可重复的量化质检（打分/校验/合规）；Skill = AI 会话内的生成与分析能力。**资产永远是 novel-lab 的 JSON，不是 Skill 的输出**。
