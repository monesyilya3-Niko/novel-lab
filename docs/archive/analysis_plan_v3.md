## 一、Skill工作流整合

### 1.1 使用的Skill

| Skill | 核心能力 | 在本计划中的应用 |
|-------|----------|-----------------|
| **open-novel-writing** | 章节规划、正文生成、评审反馈、自动化推进 | 生成章节Spec、评审打分、批量推进 |
| **novel-writing** | 伏笔追踪、冲突检测、状态管理 | 伏笔回收检查、冲突检测、进度追踪 |
| **novel-expert** | 创作指导、评论分析 | 写作技巧应用、质量分析 |

## 七、执行流程（详细版）

### Phase 0: 初始化（一次性）

```
1. 创建项目结构
   ├─ mkdir 设定/ 规格/ 正文/ 评审/ 追踪/ 报告
   └─ 初始化伏笔追踪表、状态文件

2. 加载拆书资产
   ├─ 读取 voice-card.json → 生成角色声线卡
   ├─ 读取 craft-card.json → 提取笔法技巧
   └─ 读取 genre-pack.json → 提取题材规范

3. 分割章节
   └─ 将160章分割为独立文件
```

### Phase 1: 逐章重写（每组5章）

```
对每组5章执行：

Step 1: 章节规划（open-novel-writing: Spec生成）
├─ 读取原文
├─ 分析结构（开头/发展/收束）
├─ 提取关键事件
├─ 生成章节Spec（yaml）
└─ 连贯性检查（读取前3章Spec）

Step 2: 正文生成（open-novel-writing: 正文生成）
├─ 读取章节Spec
├─ 读取voice-card（角色声线）
├─ 读取craft-card（笔法技巧）
├─ 读取genre-pack（题材规范）
├─ 生成正文（遵守铁律）
└─ 保存到正文/第XXX章.txt

Step 3: 质量检测（novel-lab: chapter_check + consistency）
├─ 运行 chapter_check.py（12维100分制）
├─ 运行 consistency.py（五维一致性）
└─ 记录分数

Step 4: 评审反馈（open-novel-writing: 5角色评审）
├─ 阅读者评审
├─ 编审评审
├─ 故事家评审
├─ 文学顾问评审
└─ 毒舌读者评审

Step 5: 自动修订（如果不达标）
├─ 分析问题（P0/P1/P2）
├─ 执行修订
├─ 重新检测
└─ 最多修订3轮

Step 6: 伏笔追踪（novel-writing: 伏笔检测）
├─ 检查本章伏笔回收情况
├─ 登记新埋下的伏笔
└─ 预警连续3章未回收的伏笔
```

### Phase 2: 连贯性检查（每组5章完成后）

```
1. 人物状态一致性
   ├─ 检查人物情绪发展是否连贯
   └─ 检查人物关系变化是否合理

2. 时间线合理性
   ├─ 检查时间顺序是否正确
   └─ 检查时间跨度是否合理

3. 剧情逻辑
   ├─ 检查事件因果关系
   └─ 检查是否存在逻辑漏洞

4. 场景衔接
   ├─ 检查场景转换是否自然
   └─ 检查地理位置是否一致
```

### Phase 3: 全书质检（160章完成后）

```
运行 novel.py 质检：

1. 跨章重复检测
   ├─ 重复章节（>70%相似）
   ├─ 重复段落（>30字）
   └─ 重复句子（>12字跨≥3章）

2. 情节连贯性
   ├─ 时间线矛盾
   └─ 人物情绪矛盾

3. 风格一致性
   ├─ 比喻密度波动
   └─ 情绪写法模式漂移

4. 凑字数检测
   ├─ 段落重复
   └─ 环境描写占比过高（>40%）

5. 乱编检测
   ├─ 人名错误
   └─ 数字矛盾

6. AI味检测
   ├─ 作者预告旁白
   ├─ 记忆闪回模板
   └─ 伤口比喻等8种
```

## 九、红线规则（Skill整合）

### P0 - 绝对禁止（出现=必须重写）

| 来源 | 禁止项 | 说明 |
|------|--------|------|
| open-novel-writing | 明显AI词汇 | "众所周知"、"不言而喻" |
| open-novel-writing | 感悟式结尾 | "他明白了..."、"她终于懂得..." |
| open-novel-writing | 感叹式结尾 | "真是太..."、"多么..." |
| open-novel-writing | 上帝视角 | "所有人没想到..." |
| genre-pack | 禁用词 | 恍若/霎时/眸/幽幽/宛如/仿佛/深邃/凝视/嘴角上扬/眸光/薄唇 |
| genre-pack | 直陈式情绪词 | "非常悲伤"、"极度快乐" |

### P1 - 建议避免（出现=建议修改）

| 来源 | 避免项 | 说明 |
|------|--------|------|
| open-novel-writing | 套路化表达 | 网文老梗堆砌 |
| open-novel-writing | 流水账 | 无意义的情节推进 |
| open-novel-writing | 抽象心理 | "他感到很..."、"她觉得..." |
| open-novel-writing | 排比句 | 连续相同句式 |
| open-novel-writing | 代词开头 | 连续"他/她/它"开头 |
