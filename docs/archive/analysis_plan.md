# 《暮冬念春》全面深度分析计划

## 目标
对《暮冬念春》160章进行全面深度分析，每5章为一组进行检测、修复、连贯性检查，确保每章达到95分以上。

## 分析流程

### 第一阶段：分组分析（32组，每组5章）
1. **分组策略**：
   - 第1组：第1-5章
   - 第2组：第6-10章
   - ...
   - 第32组：第156-160章

2. **每组分析步骤**：
   a. **质量检测**：使用`novel.py 检查`命令对每章进行12维100分制评分
   b. **问题识别**：记录所有低于95分的章节及其扣分项
   c. **修复策略**：
      - 疲劳词过多：重写相关段落
      - 对话占比异常：调整对话与叙述比例
      - 体感词不足：增加体感描写
      - 短段过多：合并段落或增加内容
      - 禁忌词出现：替换为合规表达
      - AI味过重：重写模板化句子
   d. **重写执行**：使用`novel.py 写作`命令重写问题章节
   e. **二次检测**：重写后重新评分，确保达到95分以上
   f. **连贯性检查**：检查5章之间的剧情连贯性、人物一致性、时间线合理性

### 第二阶段：跨组连贯性检查
1. **剧情连贯**：检查相邻组之间的剧情衔接
2. **人物一致**：确保人物性格、关系发展一致
3. **时间线**：检查时间线合理性
4. **伏笔回收**：检查伏笔是否合理回收

### 第三阶段：全书质检
使用`novel.py 质检`命令进行全书内容质检：
1. 跨章重复检测
2. 情节连贯性
3. 风格一致性
4. 凑字数检测
5. 乱编检测
6. AI味检测

## 质量标准
- **章节质量**：每章95分以上（12维100分制）
- **一致性**：每章90分以上（五维一致性打分）
- **连贯性**：5章之间无逻辑矛盾、时间线错误、人物性格突变
- **全书质检**：无严重问题（红色警告）

## 修复策略
1. **疲劳词过多**：
   - 替换"了"字过多的句子
   - 减少情绪标签词
   - 增加动作描写替代直接情绪表达

2. **对话占比异常**：
   - 对话过多：增加叙述和描写
   - 对话过少：增加对话推动剧情

3. **体感词不足**：
   - 增加视觉、听觉、触觉、嗅觉、味觉描写
   - 使用体感词表达情绪

4. **短段过多**：
   - 合并相关短段
   - 增加细节描写

5. **禁忌词出现**：
   - 使用题材包中的禁用词替换
   - 保持表达自然

6. **AI味过重**：
   - 避免模板化句子
   - 增加个性化表达
   - 使用具体细节替代泛泛描述

## 执行顺序
1. 第1-5章：分析、修复、连贯性检查
2. 第6-10章：分析、修复、连贯性检查
3. ...
4. 第156-160章：分析、修复、连贯性检查
5. 全书质检
6. 最终报告

## 工具使用
- **检测工具**：`novel.py 检查`（12维100分制）
- **修复工具**：`novel.py 写作`（三维度改写循环）
- **连贯性检查**：人工审核 + 自动化检测
- **全书质检**：`novel.py 质检`（6类检测）

## 进度跟踪
- 每完成一组5章，更新进度
- 记录每章分数变化
- 记录修复内容
- 记录连贯性问题

## 预期成果
- 160章全部达到95分以上
- 全书连贯性无问题
- 全书质检无严重问题
- 最终分析报告
