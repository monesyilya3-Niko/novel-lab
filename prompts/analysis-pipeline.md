# 拆书引擎 · 四遍扫描 Prompt 链

## 核心工程约束

一本网文动辄 100 万字，塞不进任何模型的上下文。**全书通读是伪命题**，必须分层采样。

这里是所有同类项目做不深的真实原因——不是不想分析，是不知道怎么在有限上下文里拿到有代表性的样本。

---

## 采样策略

### 三段式采样（默认）

| 段位 | 取样范围 | 章数 | 目的 |
|---|---|---|---|
| 开篇段 | 第 1-10 章 | 全取 | 商业层核心，决定点击率与留存，必须逐章精读 |
| 中段 | 25%、50%、75% 位置各取连续 5 章 | 15 | 稳定期文风与节奏基准 |
| 高潮段 | 每卷末 2 章 | 按卷数 | 爆发章的写法，与日常章对比 |

**总量控制在 25-35 章、约 8-12 万字。** 这个量级单次上下文放得下，成本可控，代表性够用。

### 采样原则

- 开篇必须全取。这段的信息密度和商业价值远高于其他部分。
- 中段取样必须**连续**。孤立单章看不出节奏，连续 5 章才能观察到起伏。
- 高潮章与日常章必须**成对**分析，单看高潮会高估作者的平均水平。
- 样本不足 10 章时，`meta.confidence` 强制 ≤ 0.6，且禁止生成题材包。

---

## Pass 1 · 结构层

**输入**：全部采样章节的「章节摘要 + 章末 500 字原文」
**为什么这样切**：结构分析不需要全文，摘要足够看清骨架；但章末必须给原文，因为钩子藏在具体措辞里。

**指令要点**：

```
你在拆解一本网文的结构骨架。目标不是评价好坏，是提取可复用的结构规律。

对每一章标注：
1. 章节功能（铺垫/推进/转折/爆发/缓冲/过渡）
2. 本章节拍序列（3-5个动作，用「谁做了什么导致什么」的因果句式）
3. 章末钩子类型 + 强度打分（1-10）
4. 埋设的伏笔 / 回收的伏笔

然后跨章聚合：
5. 钩子类型的频次分布，以及同类钩子的最小间隔
6. 爆发章出现的周期规律
7. 伏笔的平均跨度、最大跨度、同时挂起条数

【硬性约束】
- 钩子骨架必须抽象成句式模板，禁止摘抄原文。
  ✗ "他缓缓抬起头，眼中寒光一闪"
  ✓ "[静态动作]+[视觉细节暗示危险]"
- 节拍必须写因果关系（所以），不能写时间顺序（然后）。
  这是判断结构好坏的关键——流水账的特征就是只有"然后"。
```

**输出**：`structure` 字段的 JSON 片段

---

## Pass 2 · 人物层

**输入**：从采样章节中**抽取所有对话行 + 前后各一句上下文**，按角色分组。
**为什么这样切**：角色声线藏在对话里，描写段落是干扰项。抽完对话后数据量降到原文的 20% 左右，能覆盖更多章节。

**指令要点**：

```
你在提取角色的可执行声线特征，不是写人物评论。

对每个出场≥5次的角色，提取：
1. 单次发言平均字数
2. 口头禅、语气词习惯
3. 【拒绝方式】——这个角色怎么说"不"。这是区分角色最有效的单一维度，
   优先级高于其他所有特征。
4. 生气时的表达方式
5. 说话时的固定小动作
6. 【绝不会说的话】——反向清单。写作时防串味主要靠这个，
   正向描述容易被模型稀释，反向禁令更硬。

再看成长弧：
7. 起始状态 → 结束状态
8. 发生质变的章节号
9. 弧光类型

【硬性约束】
- 不要输出"性格开朗""城府很深"这类形容词，那是评论不是资产。
  要输出"被质疑时先笑一声再反问"这种能直接执行的行为规则。
- never_says 至少给 3 条，宁缺毋滥但不能空。
```

**输出**：`dialogue.character_voices` 字段

---

## Pass 3 · 文风层

**输入**：连续 3 章全文（选中段稳定期，避开开篇和高潮）+ 1 章高潮全文
**为什么这样切**：文风分析需要完整段落肌理，摘要和对话抽取都会破坏。但只需要少量样本——文风是高度稳定的特征。

**量化部分先跑脚本，不要让模型数数。**

```
脚本产出（jieba + 正则，毫秒级）：
- 句长分布直方图、长短句比例
- 段落行数分布、单句成段占比
- 对话/描写/心理占比
- 词频表、TTR
- 五感词占比

模型只做脚本做不了的定性判断：
1. 【情绪写法模式】直陈式/体感式/动作外化/环境投射。
   这一项权重最高——它直接决定成稿有没有AI味。
   AI默认写"他很愤怒"，人类作者写"后槽牙咬得发酸"。
2. 身体反应词库（作者惯用的生理反应表达）
3. 短句爆发出现在什么场景（不是平均句长，是节奏的触发条件）
4. 单句成段用在什么位置
5. 比喻的取材领域（不是具体喻体）
6. 【负空间】全书未出现的常见词——文风指纹的反面

【硬性约束】
- examples 里的 pattern 必须是骨架，配 anti_pattern 反例。
- 不要报告平均句长这类孤立数字，要报告"什么场景下句子变短"。
  前者是描述，后者能指导写作。
```

**输出**：`narration` + `emotion_handling` + `imagery` + `banned` 字段

---

## Pass 4 · 商业层

**输入**：第 1-10 章全文 + 各卷首末章 + 付费卡点前后 3 章
**为什么这样切**：商业价值集中在开篇和卡点，中段稀薄。

**这一遍是本项目的差异化所在，其他项目全都没有。**

```
你在做的是留存与转化分析，视角是「读者为什么留下/离开/付费」。

前3章逐段拆（这部分不能省，决定点击率）：
1. 开篇300字承担什么功能
2. 第一个钩子出现在第几字
3. 主角登场方式、金手指出现时机
4. 冲突引入位置
5. 刻意规避了哪些开篇错误

全书爽点分析：
6. 每千字爽点次数
7. 爽点类型分布（打脸/升级/收益兑现/身份揭露/他人认可/反杀）
8. 【每类爽点的铺垫字数】——铺垫不足则无力，过长则流失。
   这个数字是可直接复用的写作参数。
9. 连续无爽点的最大章数（干旱期容忍度）

付费与节奏：
10. 卡点位置、卡点手法、卡点前蓄力策略
11. 该题材的流失高危位置及规避手法

【硬性约束】
- 所有密度数字必须标注计算口径（按字数还是按章）。
- buildup_length 必须给具体数字，"适当铺垫"这种输出不接受。
```

**输出**：`commercial` 字段

---

## Pass 5 · 聚合（≥3 本时才执行）

单本出声线卡，多本才出题材包。

```
输入：同题材 3-5 份声线卡 + 各自的 structure/commercial 片段

任务：
1. 求交集 → 题材铁律（所有书都遵守的）
2. 求差集 → 作者个人风格（仅某本独有的，留在声线卡不上升到题材包）
3. 冲突项 → 标记为「流派分歧」，不做强制规则

【关键判断】
出现在 ≥80% 样本中的特征 → iron_rules
出现在 40%-80% → 建议项，不强制
出现在 <40% → 个人特色，不入题材包

宁可题材包薄一点，也不要把个人风格误判成题材铁律。
后者会让所有作品写成一个味道。
```

## 版权合规检查（每一 Pass 后强制执行）

脚本自动扫描输出的 JSON：

```python
# 任一命中即拒绝入库
1. 连续 12 字以上与原文完全匹配 → REJECT
2. abstraction_level == "verbal" → REJECT
3. contains_verbatim == true → REJECT
4. 单个字段内引号包裹的原文片段 > 20 字 → WARN + 人工复核
```

**原则**：写作技法不受版权保护，具体表达受保护。
资产库里存的必须是"怎么做"，不能是"他写了什么"。

这条线卡死了，后面商业化才走得通。
